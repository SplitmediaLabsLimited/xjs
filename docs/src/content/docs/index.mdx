XJS Framework provides JavaScript APIs for XSplit Broadcaster extensions, source
plugins, dialogs, scenes, sources, items, system devices, and output workflows.

Use these docs to install XJS, connect extensions and source plugins to XSplit
Broadcaster, and inspect the APIs available to integrations.

## What You Can Find Here

- Quick Start covers the package setup and host connection flow.
- API Reference documents the supported package entry point and public classes.
- Component Fixtures show rendered examples used by the regression harness.
- Contributor Reference exposes source-level docs for maintainers, separate from
  the stable public API.

## Runtime Compatibility

The package API remains stable. The browser bundle and XSplit harness target CEF
103 compatibility for XSplit Broadcaster-hosted integrations.

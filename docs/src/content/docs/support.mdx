Got questions? Need help? We have a community of developers who are interested
in solving plugin and Broadcaster integration problems. Use these channels when
you need help with XSplit JS Framework.

- [Support Chat](https://support.xsplit.com/) - Ask us questions at XSplit
  Support.
- [Discord](https://discord.gg/UdynF68) - Chat with the community.

## Found a Bug?

Please report framework bugs in the
[GitHub issue tracker](https://github.com/SplitmediaLabsLimited/xjs/issues/new).
